# SG85 Chi Son 2 · SG85 Saigon 1985

Two fonts by Thái Hiếu (FontZin.com) from the free Saigon Xưa font set (10 fonts), both "Version 1.00 - Thiet ke boi
Thai Hieu". They are the type of the Đìzai talk poster "Design System trong kỷ nguyên AI":

- **SG85-CHI SON 2** — the title face (unicase display).
- **SG85-Saigon 1985** — the script accent, for a few short words (names, kickers such as "About me", labels).

- The set is published by FontZin (https://fontzin.com/10-font-sai-gon-xua/). Befonts lists the set as free for
  commercial use, resale not allowed (https://befonts.com/sg85-chi-son-font.html); the CHI SON 1 download from the
  same set ships a licence file reading "License: Commercial Use Allowed".
- OS/2 `fsType` is 0 (installable embedding), so it may be served as a web font.
- OS/2 `fsType` is 0 for both fonts (installable embedding).
- The files were supplied by the user (2026-10-12); neither has a copyright record in its name table.

Files:

- `SG85-ChiSon2.ttf`, `SG85-Saigon1985.ttf` — the original fonts, for installing on a desktop (Figma, Keynote).
- `SG85-ChiSon2.woff2`, `SG85-Saigon1985.woff2` — the same fonts converted with fontTools, for the web.
- `sg85.css` — the `@font-face` rules for HTML slides: `"SG85 Chi Son"` and `"SG85 Saigon 1985"`.

Both fonts cover every Vietnamese letter. Chi Son is unicase (lower case uses the capitals). Their accents rise high
above the letters, so Vietnamese titles need a line height of about 1.2.
