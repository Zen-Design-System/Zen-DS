# SG85 Chi Son 1

SG85-CHI SON 1, version 1.00, by Thái Hiếu (FontZin.com), part of the Saigon Xưa font set.

- Copyright 2022 FontZin.Com. Font metadata: "Free font 100%, Copyright belongs to ThaiHieu@FontZin.Com".
- Licence file shipped with the download (Befonts): "License: Commercial Use Allowed" —
  https://befonts.com/sg85-chi-son-font.html
- Befonts' listing adds that resale of the font is not allowed.
- OS/2 `fsType` is 0 (installable embedding), so it may be served as a web font.

Files:

- `SG85-ChiSon1.ttf` — the original download, for installing on a desktop (Figma, Keynote).
- `SG85-ChiSon1.woff2` — the same font converted with fontTools, for the web.
- `sg85.css` — the `@font-face` rule for HTML slides.

Not included: "SG85-CHI SON 2" and "SG85-Saigon 1985", which the Đìzai talk poster uses; they are separate
fonts in the same set.
