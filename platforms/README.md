# Native token layers

Generated by `npm run tokens:native` from `src/tokens/catalog.generated.json` (which `npm run tokens:build` writes from the Figma exports). Do not edit the generated files.

| Platform | Package | Files |
| --- | --- | --- |
| SwiftUI | `platforms/swift` (Swift Package `ZenTokens`) | `ZenTokens.swift` (hand-written engine), `ZenTokenNames.swift`, `ZenTokenData.swift` (generated) |
| Flutter | `platforms/flutter` (`zen_tokens`) | `lib/zen_tokens.dart` (hand-written engine), `lib/src/zen_token_names.dart`, `lib/src/zen_token_data.dart` (generated) |

## How a value is found

Like the CSS: every collection has one active mode and the first mode is the default. A `ZenContext` names the modes that differ (for example `mode-colors-semantic: Dark`, `component-colors-theme: Brand - S1`, `component-size: Compact`, `corner-radius: Smooth`). An alias `{Token/Name}` is followed with the same modes. A collection that does not have the requested mode uses its first mode.

```swift
let dark = ZenContext.dark.with(ZenCollection.cornerRadius, "Smooth")
let fill = ZenTokens.shared.color(ZenToken.colorBackgroundSurfaceDefault, dark)   // SwiftUI Color
let gap  = ZenTokens.shared.number(ZenToken.spacingGap2XSmall)                    // Double, in px
```

```dart
final dark = ZenContext.dark.withMode(ZenCollection.cornerRadius, 'Smooth');
final fill = ZenTokens.instance.color(ZenToken.colorBackgroundSurfaceDefault, dark); // Color
final gap = ZenTokens.instance.number(ZenToken.spacingGap2XSmall);                   // double, in px
```

Token names are the Figma names (`Color/Background/Surface/Default`); the constants are the same names in camelCase. Numbers are px (font weights are plain numbers), colours are `#RRGGBB` or `#RRGGBBAA`.

## Parity

`scripts/build-native-tokens.mjs` holds the reference resolver. It writes `platforms/tests/vectors.json` (its answers for 795 token × mode-context pairs) and copies it next to the Swift and Flutter tests, which assert their own resolver returns the same. `npm run tokens:native:check` fails when these files are stale or a token cannot be resolved in any of its collection's modes.

Run the platform tests on a machine with the toolchain: `cd platforms/swift && swift test`, `cd platforms/flutter && flutter test`.

## Text styles

Figma text styles are stored as the token names they bind (family, size, weight, line height, letter spacing) and resolved in the context, so a style follows the typography mode (`typography-configuration`: Dashboard, Popular, Mobile).

```swift
Text("Title").zenStyle(ZenTextStyleName.heading2, context: ZenContext.standard.with(ZenCollection.typographyConfiguration, "Mobile"))
let style = ZenTokens.shared.textStyle(ZenTextStyleName.bodyBaseMedium)   // family, size, weight, lineHeight, letterSpacing, uppercase
```

```dart
final style = ZenTokens.instance.textStyle(ZenTextStyleName.bodyBaseMedium)?.textStyle;   // a Flutter TextStyle
```

Weights such as 450 and 550 snap to the nearest step the platform has. SwiftUI has no exact line-height setter, so `lineSpacing` is approximate. Flutter has no text-transform: apply `toUpperCase()` when `uppercase` is true. The font family (Inter) must be installed or bundled by the app.
