# Zen Design System context pack

The hand-off for implementation sessions: the token contract, Figma evidence, component ownership rules, interaction
policy and verification commands.

Start with:

1. [`AGENTS.md`](../../AGENTS.md) — how to work in this repo (definition of done, commands, where things live).
2. [Design-system context](design-system-context.md) — the source of truth and implementation contract.
3. The newest `session-log-<date>.md` in this folder — what was checked and changed most recently

Related detailed documents in the parent `docs/` directory remain authoritative for their subject area, especially
[the Figma-to-platform workflow](../figma-to-platform-workflow.md), [the template lock](../platform-template-lock.md),
