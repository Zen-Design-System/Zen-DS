# Studio Builder GĐ5: xuất code React, gói handoff, ảnh tải lên (spec, 2026-10-07)

**Trạng thái: user duyệt 2026-10-07 · xong 2026-10-07 (M1–M5)** (Q1 React **và HTML** · Q2 Promote vào `src/templates/studio` · Q3 PNG chụp

`docs/research/studio-builder-export-2026-10-05.md`, cộng ảnh tải lên (user chốt 2026-10-06 dời sang GĐ5). GĐ0–GĐ4 và
GĐ3b đã xong.

## 1. Mục tiêu và tiêu chí xong

Trang làm trong Studio đi được tới tay dev:
1. **Export** một trang builder ra component React (`.tsx`) dùng được ngay:
   - Copy, hoặc Download;
   - prototype thành handler có tên: `onNavigate("pay")`, overlay dùng `useState`, toast dùng `useToast`;
   - mock data thành `interface` cùng dữ liệu mẫu.
2. **Gói handoff** `<page>-handoff.zip`, gồm:
   - code đã compile;
   - file nguồn design `<page>.zen.tsx`;
   - `handoff.md` tự sinh;
   - ảnh dùng trong trang;
   - PNG từng màn hình.
3. **Ảnh tải lên:** Assets › Photos › Upload. Ảnh lưu trong trình duyệt, dùng như ảnh mẫu của thư viện.
4. **Promote** (chỉ dev server, admin): ghi trang thành một template trong repo, chạy `tsc` và harness, báo kết quả.

Xong khi các dòng E2E nhóm `handoff` (HO-xx) đều works trên dev server và `npm run studio:build-check`. Code xuất từ mọi
trang mẫu phải qua `tsc` và usage-guard.

## 2. Hiện trạng (rà code ngày 2026-10-07)

- Trang builder là `*.zen.tsx` theo dialect (`tools/studio/dialect.mjs`). Dialect đã có:
  - `mock` cùng `.map` trên mock;
  - `state` của Screen (empty, loading, error);
  - `proto.navigate/open/close/back/toast/link`.
- My pages › **Export file** đã tải được `.zen.tsx`; Import mở lại được. Chưa có bước compile ra React thường.
- Ảnh: Assets › Photos chỉ có ảnh mẫu của platform (`zen-media:<key>`); chưa tải ảnh của mình lên được.
- Repo chưa có thư viện zip, ảnh chụp DOM hay Playwright chạy trong trình duyệt.

## 3. Thiết kế

### 3a. Compile dialect → React (M1)

`tools/studio/compile.mjs` (isomorphic, chạy được trong trình duyệt như engine) đọc cây trung lập của `parsePage` rồi
viết một file `.tsx`:

- **Component:**
  - `export function <TênTrang>Page(props: <TênTrang>PageProps)`;
  - mỗi Screen là một nhánh `screen === "id"`, mặc định là Screen đầu tiên;
  - `state` của Screen thành điều kiện theo prop `state`.
- **Prototype → handler:**

  | Dialect | React |
  | --- | --- |
  | `proto.navigate("x")` | `setScreen("x")` cùng `onNavigate?.("x")` |
  | `proto.open("x")` | `setOverlay("x")` |
  | `proto.close()` | `setOverlay(null)` |
  | `proto.back()` | lịch sử screen; nếu không còn thì gọi `onBack?.()` |
  | `proto.toast({…})` | `toast({…})` (`useToast`) |
  | `proto.link(url)` | `href` |

  Mỗi chỗ có comment `// TODO(dev):` nói cần nối gì.
- **Overlay:** mỗi Overlay frame thành phần tử của nó với `open={overlay === "x"}` và `onOpenChange`.
- **Dữ liệu:**
  - `mock` thành `export const mock = {…}` cùng `interface` suy từ dữ liệu;
  - `.map` giữ nguyên, thêm `key`.
- **Ảnh:** `zen-media:` / `zen-asset:` thành `import photo from "./assets/<file>"` (trong zip). Khi Copy, đó là một import
  có ghi chú đặt file vào đâu.
- **Import:**
  - component từ `@zen/design-system`;
  - dòng đầu: `// Generated by Zen Studio from <page>.zen.tsx. Edit the design, then export again.`

### 3b. Export dialog (M1)

- Mở từ menu My pages và nút Export trên thanh trên khi đang ở trang builder.
- Ba tab:
  - **React** (`.tsx`, xem trước bằng Code view có highlight);
  - **HTML** (thêm ở M2);
  - **Design file** (`.zen.tsx`).
- Nút Copy và Download.
- Không có dev server vẫn chạy được (compile trong trình duyệt).

### 3b'. HTML (M2, user chọn React và HTML)

- **Nguồn:** trang đúng như canvas render nó, vì cùng là component Zen.
  - Mỗi Screen và Overlay frame được ghi DOM thành `screens/<id>.html`.
  - Bỏ thuộc tính của Studio (`data-zen-*`, `data-studio-*`), phần ẩn và transform của canvas.
  - Overlay được vẽ ở trạng thái mở.
- **`styles.css`:** các rule của thư viện mà trang dùng:
  - định nghĩa token (`:root` và các thuộc tính mode);
  - rule `.zen-*`;
  - `@font-face`, `@keyframes`.
  Các rule này được đọc từ CSS đang nạp.
- **Giới hạn:** HTML là markup tĩnh. Menu, dialog, tab, ô nhập không có JavaScript, nên không tự mở hay đổi.
  - `handoff.md` ghi rõ từng chỗ cần JS.
  - Bản React thì có đủ.
- **Kiểm chứng:** E2E mở từng file HTML trong một trang trắng cùng `styles.css`, chụp màn hình rồi so với screen trên
  canvas. Độ lệch phải dưới ngưỡng.

### 3c. Gói handoff (M2)

- `<page>-handoff.zip`, viết bằng một bộ ghi zip nhỏ không nén, không thêm dependency. Gồm:
  - `<Page>.tsx`;
  - `<page>.zen.tsx`;
  - `assets/*`: ảnh mẫu và ảnh tải lên mà trang dùng;
  - `screens/<id>.png`;
  - `handoff.md`.
- **`handoff.md`** (§6 spec export, tự sinh, không viết tay):
  - cài đặt: phiên bản `@zen/design-system`, `styles.css`, props `ZenProvider` theo preview modes của trang;
  - component dùng, mỗi cái link guideline và API;
  - token và text style dùng;
  - luồng prototype: screen, overlay, handler cần viết;
  - data contract;
  - ghi chú a11y lấy từ guideline.
- **PNG từng screen** (câu hỏi Q3):
  - chụp trong trình duyệt: DOM của frame vẽ qua SVG `foreignObject`, kèm CSS đang dùng;
  - đây là "best effort": ảnh và font được nhúng; phần nào không vẽ được thì ghi vào `handoff.md`.

### 3d. Ảnh tải lên (M3)

- Assets › Photos thêm nút **Upload**, kéo thả cũng được: PNG, JPEG, WebP, GIF, SVG, tối đa 5 MB mỗi ảnh.
- Ảnh lưu thành blob trong IndexedDB (PageStore). Trang ghi `src="zen-asset:<id>"`, là literal nên dialect vẫn hợp lệ.
- Renderer và Play đổi `zen-asset:` thành object URL.
- Export và zip đóng gói file ảnh. Import `.zen.tsx` thiếu ảnh thì hiện "Ảnh thiếu" và cho thay ảnh khác.
- Thư mục liên kết (Link folder): ảnh được ghi vào `assets/` cạnh trang.

### 3e. Promote (M4, câu hỏi Q2)

- Chỉ dev server, role admin.
- `POST /promote`:
  - ghi code compile thành `src/templates/studio/<Name>Template.tsx`, cùng ảnh vào `src/templates/studio/assets/`;
  - chạy `tsc` và usage-guard trên file đó;
  - báo kết quả. Không tự tạo PR: user chạy `npm run ship` khi muốn.

## 4. Không làm ở GĐ5

- HTML có tương tác (JavaScript cho menu, dialog…): HTML ở GĐ5 là markup tĩnh.
- Đọc ngược code đã sửa tay vào trang (§7 spec export: một chiều).
- Đồng bộ ảnh tải lên giữa các máy (ảnh nằm trong trình duyệt và trong zip).
